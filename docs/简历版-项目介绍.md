# 智析 RAG（ZuoAI-Agent）— 简历版

## 项目介绍

基于 Spring AI  构建企业级检索增强生成（RAG）对话系统，支持 PDF/Markdown/TXT 多格式文档解析入库与语义问答，涵盖多通道检索、意图分类、熔断路由、对话记忆等核心模块。

---

## 核心亮点

**① 多通道并行检索**
基于 CompletableFuture 同时发起全局向量检索与意图定向检索两条通路，结果意图定向优先合并去重，有效提升召回率与检索精度。

**② Chat / Embedding 双维熔断路由**
为 Chat 与 Embedding 分别实现多模型候选三态熔断器（CLOSED → OPEN → HALF_OPEN），连续失败自动熔断、定时探测恢复；Chat 路由额外引入首包探测，拦截空流响应触发切换，实现 AI 服务零感知故障转移。

**③ 意图树三级分类缩小检索空间**
构建领域→类目→话题三级意图树，通过 LLM 对用户查询分类后将检索范围收敛至目标知识库；对闲聊/系统意图短路处理，跳过向量检索直接回复，降低无效调用开销。

**④ 全流水线降级容错**
RAG 流水线（改写→分类→检索→重排→Prompt 组装）各阶段独立捕获异常并降级，改写失败回退原始 Prompt，检索失败触发兜底回复，任意单点故障不阻断整条链路。

**⑤ LLM 重排序提升上下文质量**
向量检索召回后，用 LLM 对每个文档片段与问题的语义相关性打分（0~10），按分数降序取 Top-3 注入 Prompt，相比纯余弦相似度排序显著提升答案准确率。

**⑥ 持久化对话记忆与摘要压缩**
基于 PostgreSQL 持久化多轮对话记忆，当会话消息超过阈值（默认 10 轮）时自动调用 LLM 压缩最旧的一半消息为摘要写回数据库，在保留长期上下文的同时控制 Token 消耗。
