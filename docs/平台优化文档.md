## 一、Situation（背景/现状）

项目已完成 Phase 0-4 的核心开发，包含 4 个微服务（auth-service / zuo-ai-agent / log-monitor-service / 前端 Vue3），但在以下方面存在缺陷：

1. **模块结构混乱**：RAG 模块和管理模块菜单混在一起，用户切换页面后找不到路
2. **租户管理不完善**：团队创建/删除/树形展示有 Bug，缺少成员和负责人管理
3. **监控看板缺失**：全局看板只显示少量指标，缺少 RAG 全链路数据大盘
4. **日志系统未拆分**：CAT 打点监控和日志聚合搜索混在一起
5. **DB/Redis 监控简陋**：只有静态数据，缺少 QPS/延迟/热点/Big Key 等指标
6. **多个 Bug**：登录状态丢失、对话失败、删除不生效等

---

重新梳理模块结构，修复 P0 级 Bug，增强监控看板，优化租户管理和权限体系。

## 四、待确认问题

### 4.1 用户管理是否合并到成员管理

**当前设计**：用户管理（admin/users）和成员管理（admin/tenant 下的 Tab）是两个独立页面。

**建议**：合并到租户管理 → 成员管理 Tab，删除独立用户管理页面。理由：
- 用户管理 = 成员管理，功能重叠
- 在租户管理下统一管理更直观
- 减少路由和菜单项

**参考**：
- **Dify**：工作空间 → 成员管理，无独立用户管理页
- **Coze**：团队空间 → 成员列表，无独立用户管理
- **企业微信后台**：通讯录 → 成员管理，用户和成员是同一个概念

### 4.2 角色权限和我的信息如何设计

**参考**：

| 平台 | 个人信息 | 角色权限 |
|------|---------|---------|
| **Dify** | 右上角头像 → 个人设置 | 工作空间 → 成员管理 → 编辑角色 |
| **Coze** | 右上角头像 → 个人中心 | 团队空间 → 成员 → 角色下拉 |
| **企业微信** | 左上角头像 → 个人信息 | 后台 → 权限管理 → 角色管理 |

**建议**：
- **我的信息**：保留在租户管理 Tab 1，只读展示 + 修改密码
- **角色权限**：保留在租户管理 Tab 4，管理员可编辑角色和权限点
- 右上角头像点击 → 个人信息弹窗（快捷入口）

### 4.3 部门负责人权限范围

**参考**：

| 平台 | 负责人权限 |
|------|---------|
| **Dify** | 工作空间 Owner 可管理全部，Admin 可管理成员 |
| **飞书** | 部门负责人可管理本部门及子部门，不可越级 |
| **企业微信** | 分级管理员，可设置管理范围（指定部门） |

**建议**：
- 部门负责人可管理自己部门及子部门（向下递归）
- 不可管理上级和平级部门
- 操作记录到 `t_audit_log`，保留变更前后对比
